# 拾音（ShiYin）

一个把「歌词」做成核心体验的安卓本地音乐播放器：**点哪句歌词，就跳到哪一句**；**外语歌词一键 AI 翻译**；**睡前定时关闭**。

## ⭐ 三大主打

### 🌐 AI 歌词翻译

外语歌听不懂？一键翻译成中文。

- 全屏歌词页点「**译**」，当前歌曲逐行翻译，译文以灰色小字显示在原文下方，跟随高亮滚动
- 兼容 **DeepSeek / 通义 / GLM / Kimi** 等任意 OpenAI 兼容接口（设置 → 翻译设置，自填 Base URL + API Key + 模型名）
- **API Key 只保存在手机本地**，不进代码、不上传，隐私安全
- 可开启「**自动翻译非中文歌词**」开关（默认关闭）：只翻译非中文歌词（中文歌自动跳过），**每首歌只翻一遍**，译文本地缓存，不重复扣费
- 容错设计：逐批翻译，个别行失败自动跳过其余行，失败行可一键重试

### 📝 VTT 字幕 / 歌词点击跳转

**点哪句，就唱哪句**——这是拾音最核心的体验。

- 完整支持 **WebVTT（.vtt）** 与 **LRC（.lrc）**，带时间戳的 .txt 也能识别，纯文本 .txt 自动展示全文
- 支持多行字幕、NOTE 块、HTML 标签清理，GBK / UTF-8 编码自动识别不乱码
- 播放页点歌词行立即跳转播放；全屏歌词页高亮跟随、点击跳转、自动滚动
- 歌词自动匹配：`歌名.lrc` / `歌名.mp3.lrc` 两种命名都认，子文件夹内自动配对
- **MP3 内嵌歌词兜底**：无外部文件时自动读取 ID3 里的 USLT / SYLT 同步歌词
- 播放页**左滑**进全屏歌词页、**右滑**返回，操作零成本

### ⏱️ 定时关闭

睡前听歌、学习定时——到点自动暂停，不打扰睡眠。

- 15 / 30 / 45 / 60 分钟可选，到点自动暂停播放
- 配合**稳定后台播放**（前台服务 + 通知栏/锁屏控制）使用，锁屏也不断

## ✨ 更多亮点

- 📁 **文件夹即歌单**：指定一个大文件夹，子文件夹自动归类成歌单
- 💿 **播放页**：CD 旋转动画封面 + 当前歌词行；「列表」按钮随时查看/切换当前歌单全部歌曲

- 🎵 **歌手自动分类**：按音频元数据读取歌手分组浏览
- 🔔 **稳定后台播放**：通知栏/锁屏控制、来电自动暂停
- ⏯️ **断点续播**：大退重开恢复到上次进度
- 🎨 **深色 / 浅色双主题**，歌词字号、界面字号、歌词字体可调
- 🔍 **歌单 / 单曲实时搜索**
- 🖼️ **内嵌封面显示**：播放页 CD、歌单、歌曲列表全覆盖
- ⏺️ 支持超长音频，MP3 / M4A / WAV / FLAC / AAC / OGG 等常见格式
- 🔒 **完全本地**：除你主动开启的歌词翻译外，不联网、无广告、无账号、不收集任何数据

## 📲 安装

在 [Releases](../../releases) 下载最新 APK（或从 GitHub Actions 的构建产物获取），传到手机安装。首次使用：

1. 打开 App → 「音乐库」→ 点搜索框旁的设置 → **更换文件夹**，选择你的音乐文件夹
2. 子文件夹自动成为歌单，同名歌词（.vtt / .lrc / .txt）自动匹配
3. 点任意歌曲进入播放页，**点歌词任意一行即可跳转**
4. （可选）设置 → 翻译设置填入 API Key，全屏歌词页点「译」体验 AI 翻译

> 提示：手机可能提示「禁止安装未知来源应用」，在设置中允许即可（功能与正式版一致）。

## 🚀 从源码构建

环境要求：JDK 17 + Android SDK（compileSdk 34）。

```bash
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

仓库已配置 [GitHub Actions](.github/workflows/build-apk.yml)，推送后自动编译并上传 APK 产物，无需本地环境。

## 📁 目录结构

```
app/src/main/java/com/example/subtitleplayer/
├── MainActivity.kt        界面与导航（发现/音乐库/播放/歌词多页面）
├── MediaPlaybackService.kt  前台播放服务（后台播放、通知栏/锁屏控制、定时关闭、断点持久化）
├── SubtitleParser.kt      VTT / LRC / TXT 解析（自动识别格式、GBK / UTF-8）
├── SubtitleLine.kt        歌词行数据
├── LyricTranslator.kt     歌词 AI 翻译（OpenAI 兼容接口，分批逐行）
├── LyricTranslationCache.kt  译文本地缓存
├── LibraryScanner.kt      文件夹扫描（歌单归类、歌词匹配）
├── LibraryCache.kt        扫描结果本地缓存（启动秒开）
├── ArtistLoader.kt        歌手元数据读取与持久化
├── CoverLoader.kt         内嵌封面读取（线程池 + 缓存）
├── Id3LyricsParser.kt     MP3 内嵌歌词读取（USLT / SYLT）
├── Adapters.kt / UIAdapters.kt / SearchAdapter.kt  列表适配器
└── Model.kt               数据模型
```

# 拾音（ShiYin）

一个把「歌词」做成核心体验的安卓本地音乐播放器：**点哪句歌词，就跳到哪一句**；**外语歌词一键 AI 翻译**；**没有歌词的日语音声/歌曲，AI 识别实时生成带时间戳的歌词并逐句翻译**；**睡前定时关闭**。

## ⭐ 四大主打

### 🎤 歌词识别（日语 · 实验）

歌单里的日语音声、歌曲没有歌词文件？让 AI 听写生成。

- 设置 → **歌词识别（日语 · 实验）**，首次下载识别模型（约 165MB，**国内网络直连，无需加速器**，模型也保存在本机）
- 全屏歌词页点「**生成歌词**」→ 为当前播放的歌实时识别：**边识别边出歌词**，进度弹窗里实时预览已识别的行
- 音频同目录若有**台本文本（.txt/.srt）**，会自动检测并提示「用台本识别」——台本作为识别热词，专有名词/人名准确率更高
- 已配置翻译 API 时**逐窗实时翻译**：识别出的行立刻出中文，识别完即见双语歌词
- 生成 `.lrc` 保存到音频同目录，自动入库；识别中途取消，已完成部分也保留
- 识别结果为「听写草稿」水平，专有名词可能出错，可手动修改 lrc 文件

### 🌐 AI 歌词翻译

外语歌听不懂？一键翻译成中文。

- 全屏歌词页点「**译**」，当前歌曲逐行翻译，译文以灰色小字显示在原文下方，跟随高亮滚动
- 兼容 **DeepSeek / 通义 / GLM / Kimi** 等任意 OpenAI 兼容接口（设置 → 翻译设置，自填 Base URL + API Key + 模型名）
- **API Key 只保存在手机本地**，不进代码、不上传，隐私安全
- 可开启「**自动翻译非中文歌词**」开关（默认关闭）：只翻译非中文歌词（中文歌自动跳过），**每首歌只翻一遍**，译文本地缓存，不重复扣费
- 容错设计：逐批翻译，个别行失败自动跳过其余行，失败行可一键重试

### 📝 VTT 字幕 / 歌词点击跳转

**点哪句，就唱哪句**——这是拾音最核心的体验。

- 完整支持 **WebVTT（.vtt）** 与 **LRC（.lrc）**，带时间戳的 .txt 也能识别，纯文本 .txt 自动展示全文
- 支持多行字幕、NOTE 块、HTML 标签清理，GBK / UTF-8 编码自动识别不乱码
- 播放页点歌词行立即跳转播放；全屏歌词页高亮跟随、点击跳转、自动滚动
- 歌词自动匹配：`歌名.lrc` / `歌名.mp3.lrc` 两种命名都认，子文件夹内自动配对
- **MP3 内嵌歌词兜底**：无外部文件时自动读取 ID3 里的 USLT / SYLT 同步歌词
- 播放页**左滑**进全屏歌词页、**右滑**返回，操作零成本

### ⏱️ 定时关闭

睡前听歌、学习定时——到点自动暂停，不打扰睡眠。

- 15 / 30 / 45 / 60 分钟可选，到点自动暂停播放
- 配合**稳定后台播放**（前台服务 + 通知栏/锁屏控制）使用，锁屏也不断

## 📲 安装

在 [Releases](../../releases) 下载最新 APK（或从 GitHub Actions 的构建产物获取），传到手机安装。首次使用：

1. 打开 App → 「音乐库」→ 点搜索框旁的设置 → **更换文件夹**，选择你的音乐文件夹
2. 子文件夹自动成为歌单，同名歌词（.vtt / .lrc / .txt）自动匹配
3. 点任意歌曲进入播放页，**点歌词任意一行即可跳转**
4. （可选）设置 → 翻译设置填入 API Key，全屏歌词页点「译」体验 AI 翻译

> 提示：手机可能提示「禁止安装未知来源应用」，在设置中允许即可（功能与正式版一致）。

## 🚀 从源码构建

环境要求：JDK 17 + Android SDK（compileSdk 34）。

```bash
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

仓库已配置 [GitHub Actions](.github/workflows/build-apk.yml)，推送后自动编译并上传 APK 产物，无需本地环境。

### 🔑 稳定签名（重要：覆盖安装不丢数据）

默认 debug 构建每次云端编译会用**临时签名**，导致手机要求"删除旧版"再安装（数据会丢）。配置一次固定签名后，以后更新都是**覆盖安装、数据保留**：

1. 仓库 Actions 页 → 手动运行 workflow → 勾选 **Generate a stable debug keystore** → 运行
2. 下载产物 `debug-keystore-b64` 里的 `keystore.b64`，打开复制全部内容
3. 仓库 Settings → Secrets and variables → Actions → New repository secret：
   - Name：`DEBUG_KEYSTORE_B64`
   - Value：粘贴刚才的内容
4. 之后每次构建都会用同一签名；**唯一一次例外**：从旧签名换到新签名的这次更新，仍需先卸载旧版（旧数据会丢，之后不再需要）

## 📁 目录结构

```

├── MainActivity.kt        界面与导航（发现/音乐库/播放/歌词/视频多页面）

├── SubtitleLine.kt        歌词行数据

├── AudioFxManager.kt / EqualizerView.kt  均衡器
├── UiUtils.kt             通用 UI 工具（toast / 时间格式化等）

├── CoverLoader.kt         内嵌封面读取（线程池 + 缓存）

├── Adapters.kt / UIAdapters.kt / SearchAdapter.kt  列表适配器

```
